# 实验 10 · PWM 驱动舵机

## 遇到的问题

舵机一直转不停，或者完全不动。

**检查**

1. 断电后**用手转舵机轴**：能无限圈转 = 360° 型；转半圈顶住 = 180° 型
2. 舵机 VCC 是否接**独立 5 V**，并且和单片机**共地**
3. 万用表量 **PA1** 对 GND 的平均电压（0°≈0.1 V，180°≈0.4 V）

**原因**

1. **360° 连续旋转舵机**：500~2500 µs 表示"反转~正转"的速度，不是角度，
   所以按一下只是换转速，会一直转 → 要换 180° 版本
2. **ST-Link 的 5 V 带不动舵机**（几百 mA），会电压跌落导致不动或复位
3. 信号线没接 PA1（TIM2_CH2），或者 PWM 频率不是 50 Hz
